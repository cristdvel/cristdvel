## Estudio publicado

**Rechazar cookies en 292 tiendas online españolas: qué pasa después, medido y
validado a mano.** Validé 81 sitios a mano y descarté mi primera cifra (34 %)
porque solo el 38,8 % de lo que marcaba el robot se confirmaba. Resultado: entre
el 13 % y el 32 % de las tiendas que se pudieron probar sigue enviando datos a
rastreadores tras pulsar «Rechazar».
[Leer el estudio](https://cristhianvelasquez.com/es/blog/estudio-rechazar-cookies-tiendas-espanolas/) ·
